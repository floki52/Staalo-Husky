# Husky Center Staalo website

A simple one-page landing page in the Lapland Warm brand style.

## What's inside

- `index.html` — the whole page (layout, colours and fonts are inside the file)
- `assets/logo-pine.png` — logo for light backgrounds
- `assets/logo-cream.png` — logo for dark backgrounds
- `assets/favicon.png` — small icon shown in the browser tab

## Put it online with GitHub Pages (free)

1. Log in to github.com and click **New repository**.
2. Name it, for example `staalo-website`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**, drag in `index.html`, `README.md` and the whole `assets` folder, then click **Commit changes**.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and click **Save**.
6. After a minute or two the page is live at `https://YOUR-USERNAME.github.io/staalo-website/`.

## Using your own domain later

When Staalo has a domain (for example huskycenterstaalo.fi):

1. In **Settings → Pages**, enter the domain under **Custom domain** and save.
2. At the domain seller, add the DNS records GitHub shows you.
3. Tick **Enforce HTTPS** once it appears.

## Things to fill in

Search the file for `[` to find every placeholder:

- **Photos:** put a photo in the `assets` folder and replace the placeholder text with
  `<img src="assets/your-photo.jpg" alt="Short description">`
- **About section:** a few sentences about Staalo
- **Partner links:** replace `#` with the Safartica and Nordic Unique Travel tour links
- **Contact:** address, phone, email
- **Social media:** Facebook and Instagram links

Tip: shrink photos to about 1600 px wide before uploading so the page loads quickly.
